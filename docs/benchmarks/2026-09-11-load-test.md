# Point-to-Point Load Test — 2026-09-11

## Method

Autocannon sent `POST /api/routes/point-to-point` requests for 15 seconds with 20 concurrent
connections and pipelining set to 1. The endpoint ran without a response cache against the
load-test script's deterministic 50,176-node/199,808-edge grid fixture. This makes the run
reproducible without committing an OSM extract or requiring Postgres and Redis.

Environment: Windows host, Node.js 24.11.1, Autocannon 8.0.0. The project runtime target remains
Node.js 22. Results are a local engineering baseline, not a production SLA.

```powershell
$env:LOAD_TEST_FIXTURE='true'
pnpm load:test
```

To exercise an ingested Compose stack instead, omit `LOAD_TEST_FIXTURE` and optionally set
`LOAD_TEST_BASE_URL`, `LOAD_TEST_CONNECTIONS`, `LOAD_TEST_DURATION_SECONDS`, and
`LOAD_TEST_PAYLOAD`. Raise `RATE_LIMIT_MAX` only for a controlled benchmark; the normal default is
100 requests per minute per IP.
